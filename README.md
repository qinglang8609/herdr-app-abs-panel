# abs（herdr-app 界面）

一套完整的 herdr-app 界面：左侧工作区列表、顶栏、右侧记忆库面板，
再加上文件树弹窗、Git 源码管理面板、侧栏底部的用量统计块。
四个模块合在这一个仓库里，一次 `install.sh` 全装上。

| 模块 | 作用 |
|---|---|
| `mods/abs` | 主界面：工作区列表、顶栏、右侧四个面板（Sessions / Todo / Index / Log）|
| `mods/files-mine` | 文件树；点文件弹窗看内容（内置 `files` 会把内容挤进窄面板）|
| `mods/changes-mine` | Git 面板：多仓库、暂存/取消暂存/丢弃、提交、推拉、分支图历史 |
| `mods/agent2api` | 侧栏底部统计块：Token / 请求 / 缓存命中 / 账号可用 / 可用积分 |

内置的 `files` 和 `changes` 每次启动会被 app 按哈希重置，改不动它们的行为，
所以这两份是独立模块；仓库的 `layouts/abs.json` 里已经把 `files` / `changes` 指向自己那两份。

## 一键安装

```sh
curl -fsSL https://raw.githubusercontent.com/qinglang8609/herdr-app-abs-panel/main/get.sh | sh
```

重复运行等于升级。

已经 clone 的，直接跑：

```sh
sh install.sh
```

装完重启 herdr-app，用 `abs` 布局（统计块、文件树、Git 面板都在这一份里）。

统计块要读自己搭的面板，凭据在 `~/.config/herdr-app/agent2api.json`（600 权限，不进仓库）：

```json
{ "base": "https://你的面板域名", "username": "...", "password": "..." }
```

没这个文件时 `install.sh` 会生成模板；已有的不动。

## 结构

```
mods/abs/                 整套界面，一个模块
├── main.js               按 part 分发
├── icons/                53 个图标
├── parts/
│   ├── side.js           侧栏顶栏 + 三行导航
│   ├── head.js           顶栏、打开菜单、页面图标
│   ├── spaces.js         工作区列表（按服务器分组）
│   ├── agents.js         Agents 运行状态（当前布局没挂载）
│   ├── panel.js          右侧记忆库面板
│   ├── space-icon.js     右键换工作区图标
│   ├── foot.js           底部设置与主题
│   ├── lib.js            公共工具
│   └── space-icons.js    工作区图标名单
└── scripts/scan.js       会话扫描

detail/                   点任务弹出的详情框
themes/                   atom-one-dark 等主题
layouts/abs.json          布局
```

布局只引用 `mods/abs` 一个模块，靠 `props.part` 取不同的块：

| part | 位置 |
|---|---|
| `side-top` | 侧栏顶栏（齿轮、折叠） |
| `sidebar` | New thread / Search / Add machine |
| `spaces` | 工作区列表 |
| `header` | 顶栏 |
| `panel` | 右侧记忆库面板 |

弹窗（不占布局位置）：`open-menu`、`quick-open`、`space-icon`。

## 右侧面板

四个页签，数据结构都从当前项目的 `.brain` 读：

- **会话**：`~/.local/share/abs-panel` 下的 pi 会话缓存。两行一条，悬停右侧出现 × 删除，每页 20 条
- **看板**：`todo.md` 的任务。行首那个勾选字符就是状态：`[ ]` 进行中、`[-]` 滞留中、`[+]` 讨论中、`[x]` 已完成（不再做）、`[~]` 搁置，子项用同一套；不分段，全部按日期倒排，最新的在上面；`[[log-日期]]` 双链会展开成 `sessions/*.md` 里的真实任务；整张卡片一起滚，翻页固定在底部
- **图谱**：只读当前目录里**最近的一份** `index.md`（不合并子项目的），分类与铁律都只来自它里面的 `##` 标题，不预设任何固定分类名；标题下面没条目的分类不列那一行；铁律卡一直在，没有铁律段时上面写「还没有铁律」
- **日志**：`log.md` 的记录，三行一条（标题 / 详情 / 作者+时间），作者没写就留空，翻页固定在底部

文件不限于 `.brain`：当前目录往下 5 层里找 `todo.md` / `log.md` / `index.md`，看板和日志把找到的几份并成一份，图谱只取最近的一份；一份都没找到才往上找两级，再没有才用该机器的 `~/.brain`。读不到的跳过，不报错。三份文件都按「能认多少认多少」解析：认不出的行只跳过这一行，不让整块变空。

### todo.md / log.md 的行格式

标准写法（方括号的顺序可以乱，但第一个方括号一定是标题）：

```
- [ ] [标题] [2026-11-16 11:00] [[作者]] [01a1c4c6-c75c-7001-…] [标签]
```

- 行首方括号是状态：`[ ]` 进行中、`[-]` 滞留中、`[+]` 讨论中、`[x]` 已完成、`[~]` 搁置；子项用同一套
- 第一个「不像状态、不像 id、不带日期」的方括号是标题
- 带日期（可带时分）的方括号是时间；`[[…]]` 是作者；`01a1c4c6-c75c-…` 这种是会话 id；剩下的方括号当标签（标签显示在标题右侧，最多 3 个，详情里列全）
- 旧写法 `id [[作者]] — 标题 — 结语 【落地】 (完成 2026-11-09 …)` 仍然能读

`log.md` 用同一套：`## [2026-11-16 11:00] [[作者]] [标题] [标签]`，方括号外是正文；
旧的 `## [时间] [[作者]] 类型 | 正文` 也照读。

点任一行弹出详情，正文就是那一行的原文（纯文本，不做 markdown、不带勾选），右上角 `×` 关闭。

状态色：进行中深绿、讨论中橙、滞留/搁置/暂停红，都是白字。

## 刷新

只刷当前页：会话/看板读 `todo.md`，图谱读 `index.md`，日志读 `log.md`。
读到才替换，读不到保留旧列表（不会先变空）。切走就停 5 秒定时器，切回先刷一次再起表。

## 主题

`atom-one-dark` 已补齐 `colors` 里的 `canvas`、`surface`、`chrome`、`raised`、`hover`、`selected`、`border`，
让终端、窗口、侧栏、卡片底色分层一致。
